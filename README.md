# PPI_whitening_iversion
Simulation code accompanying the Commentary "Revisiting prewhitening in psychophysiological interaction analysis".
The first part of the simulation code reproduces the original simulation setup provided by He et al. (2025).

**Reference:**

He, V., Tahayori, B., Vaughan, D. N., Pardoe, H. R., Jackson, G. D., Tailby, C., & Abbott, D. F. (2025). Common pitfalls during model specification in psychophysiological interaction analysis. Imaging Neuroscience, 3. https://doi.org/10.1162/imag.a.989
